  <action>
Create src/lib/disputes.ts with:

1. `extractReviewIdFromUrl(urlString: string, siteUrl: string): string | null`
   - Use native URL constructor (not regex)
   - Verify origin matches siteUrl
   - Handle two URL patterns:
     - Hash pattern: `#review-{id}` (from building page)
     - Edit pattern: `/review/edit/{id}` (from edit link)
   - Return null for invalid URLs or wrong origin
   - Catch malformed URL exceptions and return null

2. `validateDisputeForm(data: DisputeFormData): ValidationError[]`
   - Validate landlordName, landlordEmail, landlordPhone are non-empty
   - Validate landlordEmail has valid email format (simple regex)
   - Validate disputeReasons array has at least one item
   - Return array of validation errors (field + message)

3. Export TypeScript interfaces:
   - DisputeFormData: { landlordName, landlordEmail, landlordPhone, disputeReasons, disputeExplanation?, reviewUrl }
   - ValidationError: { field: string, message: string }
   - DisputeReason type: string literal union of valid reasons

4. DISPUTE_REASONS constant array with 5-6 common dispute reasons:
   - "Factually incorrect information"
   - "Defamatory or false statements"
   - "Review is for wrong property"
   - "Tenant never lived here"
   - "Contains inappropriate content"
   - "Other"
