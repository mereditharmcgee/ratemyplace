2. **Create a helper to run wrangler d1 execute with --json and parse results:**
```typescript
import { execSync } from 'child_process';

function wranglerQuery(sql: string): any[] {
  const result = execSync(
    `npx wrangler d1 execute ratemyplace-db --local --command "${sql.replace(/"/g, '\\"')}" --json`,
    { encoding: 'utf8', stdio: ['pipe', 'pipe', 'pipe'] }
  );
  return JSON.parse(result)[0].results;
}
```

3. **Create a step runner for fail-fast with context:**
```typescript
function run(stepName: string, fn: () => void): void {
  process.stdout.write(`  ${BOLD}${stepName}${RESET}... `);
  try {
    fn();
    console.log(`${GREEN}✓${RESET}`);
  } catch (err: any) {
    console.log(`${RED}✗${RESET}`);
    console.error(`\n${RED}  Failed at: ${stepName}${RESET}`);
    console.error(`${RED}  Error: ${err.message}${RESET}`);
    if (err.stderr) {
      console.error(`${RED}  Details: ${err.stderr.toString()}${RESET}`);
    }
    process.exit(1);
  }
}
```

4. **Main reset logic:**
- Print header: `\n  Reset local database\n`
- Step "Discovering tables": Query `SELECT name FROM sqlite_master WHERE type='table' ORDER BY name` via wranglerQuery
- Filter out `sqlite_sequence` and `_cf_METADATA` (SQLite/Cloudflare internals)
- If no tables to drop, print "No tables found" and exit cleanly
- Step "Dropping N tables": Build multi-statement SQL:
  - `PRAGMA foreign_keys=OFF;`
  - `DROP TABLE IF EXISTS "tableName";` for each table
  - `PRAGMA foreign_keys=ON;`
  - Write this SQL to a temp file (use `os.tmpdir()` + `path.join`) to avoid shell quoting issues
  - Execute via `npx wrangler d1 execute ratemyplace-db --local --file "tempFile"`
  - Clean up temp file with `fs.unlinkSync`
- Print each dropped table name (one per line) for visibility
- Print summary: `\n  ${GREEN}✓ Reset complete — N tables dropped${RESET}\n`

Key requirements:
- Import from 'child_process', 'fs', 'os', 'path'
- Use `writeFileSync` and `unlinkSync` from 'fs' for temp file
- Use `tmpdir` from 'os' and `join` from 'path'
- `d1_migrations` MUST be in the drop list (verified by checking it appears in the discovered tables)
- `sqlite_sequence` and `_cf_METADATA` MUST NOT be dropped
- `PRAGMA foreign_keys=OFF` MUST execute before any DROP statements
- `PRAGMA foreign_keys=ON` MUST execute after all DROP statements
- Script exits 0 on success, 1 on any error
