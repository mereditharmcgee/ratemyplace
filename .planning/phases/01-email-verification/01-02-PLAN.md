Modify the review query in src/pages/building/[slug].astro to JOIN with users table and include email_verified status.

Current query (around line 49-54):
```typescript
const reviewsResult = await db.prepare(`
  SELECT * FROM reviews
  WHERE building_id = ? AND status = 'approved'
  ORDER BY created_at DESC
  LIMIT 50
`).bind(building.id).all();
```

Updated query:
```typescript
const reviewsResult = await db.prepare(`
  SELECT r.*, u.email_verified as user_email_verified
  FROM reviews r
  LEFT JOIN users u ON r.user_id = u.id
  WHERE r.building_id = ? AND r.status = 'approved'
  ORDER BY r.created_at DESC
  LIMIT 50
`).bind(building.id).all();
```

Key changes:
- Use table alias `r` for reviews
- LEFT JOIN users table to get email_verified
- Alias as `user_email_verified` to avoid confusion with any other verified fields
- Keep existing WHERE and ORDER BY logic

This makes `review.user_email_verified` available in ReviewCard.
