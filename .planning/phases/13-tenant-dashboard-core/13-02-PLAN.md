**`src/pages/api/user/profile.ts`** — PATCH endpoint:
- Auth check: require `context.locals.user`
- Accept JSON body: `{ displayName?: string; notificationOptIn?: boolean }`
- Validate displayName: trim, 1-50 chars if provided (empty string sets to null)
- Update SQL: `UPDATE users SET name = ?, notification_opt_in = ?, updated_at = unixepoch() WHERE id = ?`
  - Bind: `displayName.trim() || null`, `notificationOptIn ? 1 : 0`, `userId`
- Return `{ success: true }`

**`src/pages/api/user/password.ts`** — PATCH endpoint:
- Auth check: require `context.locals.user`
- Accept JSON body: `{ currentPassword: string; newPassword: string }`
- Fetch user row: `SELECT hashed_password, google_id FROM users WHERE id = ?`
- If `hashed_password` is NULL and `google_id` is not NULL:
  - This is a "set password" flow for OAuth users — skip currentPassword verification
  - Validate newPassword (min 8 chars)
  - Hash with `hashPassword(newPassword)` from `src/lib/password.ts`
  - Update: `UPDATE users SET hashed_password = ?, updated_at = unixepoch() WHERE id = ?`
  - Return `{ success: true, message: 'Password set successfully' }`
- If `hashed_password` exists:
  - Verify currentPassword with `verifyPassword(currentPassword, storedHash)` from `src/lib/password.ts`
  - If verification fails, return 400: `{ error: 'Current password is incorrect' }`
  - Validate newPassword (min 8 chars)
  - Hash with `hashPassword(newPassword)`
  - Update hashed_password
  - Invalidate all sessions: `lucia.invalidateUserSessions(userId)` using `initializeLucia(db)` from `src/lib/auth.ts`
  - Return `{ success: true, message: 'Password changed. Please sign in again.' }`
- If `hashed_password` is NULL and `google_id` is NULL: return 400 (unexpected state)

**`src/pages/api/user/email.ts`** — PATCH endpoint:
- Auth check: require `context.locals.user`
- Accept JSON body: `{ currentPassword: string; newEmail: string }`
- Fetch user row: `SELECT hashed_password, google_id FROM users WHERE id = ?`
- If `google_id` is not NULL: return 400 `{ error: 'Email changes are managed through your Google account.' }`
- If `hashed_password` is NULL: return 400 (unexpected state)
- Verify currentPassword with `verifyPassword`
- If verification fails, return 400: `{ error: 'Current password is incorrect' }`
- Validate newEmail: check format with regex, trim, lowercase
- Check uniqueness: `SELECT id FROM users WHERE email = ? AND id != ?`
- If taken, return 409: `{ error: 'This email is already in use' }`
- Update: `UPDATE users SET email = ?, email_verified = 0, updated_at = unixepoch() WHERE id = ?`
- Return `{ success: true, message: 'Email updated. Please verify your new email address.' }`
