```typescript
test.describe('Concurrent Submissions', () => {
  test('concurrent duplicate reviews handled gracefully', async ({ browser }) => {
    // Increase timeout — this test fills the form twice
    test.setTimeout(120000);

    // Create two browser contexts with the same user session
    const USER_AUTH_FILE = path.join(__dirname, '../playwright/.auth/user.json');
    const [ctx1, ctx2] = await Promise.all([
      browser.newContext({ storageState: USER_AUTH_FILE }),
      browser.newContext({ storageState: USER_AUTH_FILE }),
    ]);
    const [page1, page2] = [await ctx1.newPage(), await ctx2.newPage()];

    // Helper to fill the review form through all steps up to Submit
    // (reuse or inline the form-filling logic from the happy-path test)
    async function fillReviewToSubmit(page: Page) {
      await page.goto('/review/new?building=building-30');
      await page.waitForLoadState('networkidle');

      // Unit Details — click Continue (defaults are fine)
      await page.locator('button', { hasText: 'Continue' }).click();

      // Unit Rating — rate all items with score 3
      await rateAllItemsInStep(page, 3);
      await page.locator('button', { hasText: 'Continue' }).click();

      // Building Rating — rate all items with score 3
      await rateAllItemsInStep(page, 3);
      await page.locator('button', { hasText: 'Continue' }).click();

      // Landlord Rating — rate all items with score 3
      await rateAllItemsInStep(page, 3);
      await page.locator('button', { hasText: 'Continue' }).click();

      // Additional — click Review & Submit (defaults are fine)
      await page.locator('button', { hasText: 'Review & Submit' }).click();

      // Confirm — check privacy checkbox
      await page.locator('input[type="checkbox"]').check();
      await expect(page.locator('button', { hasText: 'Submit Review' })).toBeEnabled();
    }

    // Fill both forms (sequentially — can't parallelize since workers: 1 shares D1)
    await fillReviewToSubmit(page1);
    await fillReviewToSubmit(page2);

    // Submit simultaneously
    await Promise.all([
      page1.locator('button', { hasText: 'Submit Review' }).click(),
      page2.locator('button', { hasText: 'Submit Review' }).click(),
    ]);

    // Wait for both pages to settle (either redirect to building page or show error)
    await Promise.all([
      page1.waitForURL(/\/building\/|\/review\//, { timeout: 30000 }).catch(() => {}),
      page2.waitForURL(/\/building\/|\/review\//, { timeout: 30000 }).catch(() => {}),
    ]);

    // Neither page should show a 500 error
    const body1 = await page1.textContent('body');
    const body2 = await page2.textContent('body');
    expect(body1).not.toContain('Internal Server Error');
    expect(body2).not.toContain('Internal Server Error');

    // At least one should have succeeded (redirected to building page)
    const url1 = page1.url();
    const url2 = page2.url();
    const oneSucceeded = url1.includes('/building/') || url2.includes('/building/');
    expect(oneSucceeded).toBe(true);

    // Cleanup
    await ctx1.close();
    await ctx2.close();
  });
});
```

3. The `browser` fixture is a standard Playwright fixture available on the default `test` — not specific to our custom fixtures. It should work with our extended test since `base.extend` preserves all default fixtures.

4. IMPORTANT: Both form fills happen sequentially (not Promise.all) because the form filling involves multiple page navigations and clicks that are inherently sequential. Only the final Submit click is concurrent.

5. This test uses building-30 which has 0 reviews in seed data. After the happy-path test (Plan 02) submits one review, this test submits 1-2 more. Since tests run sequentially (workers: 1), the happy-path runs first. The concurrent test's building-30 may already have 1 review. That's fine — the concurrent test is about graceful handling, not about the first review.

6. If the `fillReviewToSubmit` helper needs the `expect` function (for the enabled check), make sure it's accessible. Alternatively, simplify the helper to not include assertions — just fill and prepare.
