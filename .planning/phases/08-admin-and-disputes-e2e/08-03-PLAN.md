**Fix 3 — Lines 116-122, non-admin redirect test:**
The `authedPage.waitForURL('/')` times out because Astro's SSR `Astro.redirect('/')` sends a 302 before page HTML — Playwright's waitForURL() does not reliably capture SSR-level redirects with the default navigation event.

Replace the test body with a navigation approach that handles SSR 302 redirects:

```typescript
test('non-admin user is redirected from admin pages', async ({ authedPage }) => {
  // SSR redirect — use waitUntil: 'commit' so Playwright resolves when the 302 is sent
  await authedPage.goto('/admin', { waitUntil: 'commit' });
  // After redirect resolves, confirm we are NOT on /admin
  await expect(authedPage).not.toHaveURL(/\/admin/);
  // Dashboard Overview heading must NOT be visible — user was redirected
  await expect(authedPage.locator('h1').filter({ hasText: 'Dashboard Overview' })).not.toBeVisible();
});
```
