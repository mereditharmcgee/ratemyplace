2. **Use the `adminPage` fixture** for all admin tests (pre-authenticated admin session)
3. **Use the `authedPage` fixture** for the non-admin access control test

The test cases to implement:

**describe('Admin Page Navigation', () => { ... })**

- **'admin navigation bar contains all page links'**:
  - Use `adminPage` fixture
  - Navigate to `/admin`
  - Wait for 'Dashboard Overview' heading to be visible
  - Assert 9 nav links exist using `adminPage.locator('nav a[href="..."]')`:
    - `/admin` (Dashboard), `/admin/users`, `/admin/reviews`, `/admin/buildings`
    - `/admin/landlords`, `/admin/managers`, `/admin/verify`, `/admin/disputes`, `/admin/audit`

**describe('Admin Dashboard', () => { ... })**

- **'dashboard shows stats cards'**:
  - Navigate to `/admin` — SSR page, no networkidle wait needed
  - Assert `h1` has text 'Dashboard Overview'
  - Assert stats labels visible: 'Total Users', 'Total Reviews', 'Buildings', 'Verifications'
  - Assert section headings: "Review Status Breakdown", "Recent Reviews"

**describe('Admin Pages Render', () => { ... })**

For each of the 8 non-dashboard admin pages, create a test that:
1. Navigates to the page URL
2. Asserts the h1 heading text
3. Waits for `waitForLoadState('networkidle')` (React island data fetch)
4. Asserts at least one content element confirming the component rendered

Specific tests:
- **'users page renders'**: `/admin/users` -> "User Management", wait for networkidle
- **'reviews page renders'**: `/admin/reviews` -> "Review Management", assert status filter buttons visible (e.g. button matching /All \(/)
- **'buildings page renders'**: `/admin/buildings` -> "Building Management"
- **'landlords page renders'**: `/admin/landlords` -> "Landlord Management"
- **'managers page renders'**: `/admin/managers` -> "Property Manager Management"
- **'verification page renders'**: `/admin/verify` -> "Verification Queue"
- **'disputes page renders'**: `/admin/disputes` -> "Dispute Queue", assert filter buttons visible (Pending, Resolved, All)
- **'audit page renders'**: `/admin/audit` -> "Audit Log", assert table thead visible or "No audit logs found" text

**describe('Admin Access Control', () => { ... })**

- **'non-admin user is redirected from admin pages'**:
  - Use `authedPage` fixture (regular user, not admin)
  - Navigate to `/admin`
  - Assert URL redirected away: `await authedPage.waitForURL('/')`
  - Assert 'Dashboard Overview' heading NOT visible

- **'unauthenticated user is redirected to signin'**:
  - Use `page` fixture (unauthenticated)
  - Navigate to `/admin`
  - Assert URL contains '/auth/signin': `await page.waitForURL(/auth\/signin/)`

**IMPORTANT implementation notes:**

1. Dashboard is SSR-only — content available immediately after navigation
2. All other pages use React client:load — use `waitForLoadState('networkidle')` after goto
3. Do NOT use `page.waitForTimeout()` — use `waitForLoadState` or `waitFor()` on specific elements
4. For access control tests with `authedPage`, AdminLayout redirects non-admin users to `/`
5. Loading spinner selector: `div.animate-spin.rounded-full.h-8.w-8.border-b-2.border-teal-600`
