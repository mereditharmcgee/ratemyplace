### DASH-06 Gap Detail

**Requirement:** User receives in-app notifications for review status changes (approved, rejected, disputed)

**What works:** Notifications fire on approve, reject, and dispute resolution. NotificationsTab displays them. Bell badge shows unread count.

**What's missing:** When a landlord files a dispute against a tenant's review (POST /api/disputes), no notification is sent to the tenant. The `review_disputed` event type and message text are fully defined in `src/lib/notifications.ts` (`EVENT_MESSAGES.review_disputed`), but the dispute submission endpoint never calls `createNotification`. The tenant only learns their review was disputed by checking their dashboard.

**Fix:** Add `createNotification` call to the POST handler in the dispute submission endpoint, similar to the pattern already used in the PATCH handler for dispute resolution.
