<task type="auto">
  <name>Task 3: Create dispute submission API endpoint</name>
  <files>src/pages/api/disputes.ts</files>
  <action>
Create src/pages/api/disputes.ts with POST handler:

POST /api/disputes (public - no auth required):

1. Parse JSON body with required fields:
   - reviewUrl, landlordName, landlordEmail, landlordPhone, disputeReasons, disputeExplanation

2. Validate required fields present:
   - Return 400 with { error: 'Missing required fields' } if not

3. Extract and validate review URL:
   - Use extractReviewIdFromUrl(reviewUrl, siteUrl)
   - Return 400 with { error: 'Invalid review URL. Please paste the full URL from your browser.' } if null

4. Verify review exists in database:
   - SELECT id, building_id FROM reviews WHERE id = ?
   - Return 404 with { error: 'Review not found. Please check the URL and try again.' } if not found

5. Get building address for confirmation email:
   - SELECT address FROM buildings WHERE id = ?

6. Insert dispute record:
   - Generate UUID with crypto.randomUUID()
   - Use sanitizeText() on text fields
   - Lowercase and trim email
   - JSON.stringify disputeReasons array
   - Catch UNIQUE constraint error and return 409: { error: 'A dispute already exists for this review.' }

7. Send confirmation email (best-effort):
   - Get RESEND_API_KEY from runtime.env
   - Call sendDisputeConfirmationEmail
   - Log error if fails but don't fail the request

8. Return 201 with { success: true, disputeId }

Error handling:
- Wrap in try/catch
- Log errors with console.error
- Return 500 with { error: 'Failed to submit dispute' } on unexpected errors
  </action>
